Poner este proyecto a andar en otra PC

Cubre los dos escenarios reales: (A) migrar este mismo equipo tal cual está — con sus datos — a una PC nueva, y (B) levantar una copia limpia desde cero (clon del repo + base de datos vacía o con datos de referencia). Versión de PHP, extensiones, drivers de SQL Server, pasos de instalación — todo en un solo lugar, con índice a la izquierda.

⚠️ Lo más importante de toda la página El PHP tiene que ser exactamente 8.2.x, build Thread Safe (TS), x64. Los drivers de SQL Server (sqlsrv / pdo_sqlsrv) son archivos .dll compilados para una versión de PHP específica — el de PHP 8.2 no sirve para PHP 8.3, ni el NTS sirve para Apache. Si en la PC nueva instalás "la última versión de PHP" sin fijarte, el proyecto no arranca.

2 PHP: versión exacta y por qué importa

8.2.4 · Thread Safe (TS) · x64 Obligatorio

Confirmado corriendo php -v en este equipo:

PHP 8.2.4 (cli) (ZTS Visual C++ 2019 x64)

  • ¿Por qué 8.2 y no "la última"? El proyecto se probó y auditó explícitamente para ser compatible con PHP 7.4 hasta 8.5 (sin match(), never, mixed, tipos unión, sintaxis 8.0+), pero el que está corriendo en producción hoy es 8.2.4. Otra versión de PHP puede correr el código sin errores de sintaxis, pero necesita SU PROPIO archivo .dll del driver de SQL Server (ver sección 3) — si no coinciden exactamente, Apache no levanta el módulo o la web tira "Class sqlsrv not found".
  • ¿Por qué Thread Safe (TS) y no Non-Thread-Safe (NTS)? Apache usa el módulo php8apache2_4.dll, que requiere el build TS de PHP. Si instalás la versión NTS (la que trae XAMPP por default en algunos instaladores, o la que se baja "a mano" de php.net sin fijarse), Apache no carga el módulo PHP y la web no responde.
  • Arquitectura: x64 en todo — PHP, drivers, Apache. No mezclar con x86.
Forma más simple de no fallar acá
Instalar exactamente el mismo XAMPP (o al menos la misma versión de PHP que trae) que se usó acá, en vez de armar PHP + Apache por separado. XAMPP para Windows con PHP 8.2.x ya viene con la combinación TS + VC16 correcta.

4 SQL Server + drivers de conexión

🔴 Motor de base de datos Obligatorio

SQL Server 2022 Express, build 16.0.1190.2 (SELECT @@VERSION confirmado en vivo). Instancia con nombre VICTUS (configurable en config/connections.php → server_default), autenticación de Windows (usuario/clave vacíos = Windows Auth).

  • No hace falta que sea exactamente 2022 — el código usa T-SQL estándar (OUTPUT INSERTED, TRY_CONVERT, funciones de ventana) soportado desde SQL Server 2016/2017 en adelante. Pero para que "funcione tal cual", lo más seguro es instalar 2022 igual.
  • Edition Express alcanza para el volumen actual — ojo si a futuro alguna base se acerca al límite de 10 GB de Express, ahí sí hay que subir a Standard.
  • Las 5 bases necesarias: PORTAL_APM, Talento_Humano, PortuariaDemo, PortuariaExterna, inventario — todas en la misma instancia.

🔴 Microsoft ODBC Driver 18 for SQL Server Obligatorio

Es el runtime nativo del que dependen sqlsrv y pdo_sqlsrv por debajo — sin instalarlo en Windows, esas extensiones de PHP cargan pero fallan al conectar. Confirmado instalado en este equipo (junto con la versión 17, por compatibilidad, aunque el código pide específicamente la 18 — ver apps/talento_humano/core/Config.php, clave driver).

Se descarga gratis de Microsoft: buscar "ODBC Driver 18 for SQL Server download" — instalador msodbcsql.msi x64.

🔴 Microsoft Drivers for PHP for SQL Server (sqlsrv/pdo_sqlsrv) Obligatorio

Los archivos .dll que van dentro de php/ext/. Los que están instalados hoy:

php_sqlsrv_82_ts_x64.dll
php_pdo_sqlsrv_82_ts_x64.dll

  • El 82 del nombre = compilado para PHP 8.2. El ts = Thread Safe. El x64 = 64 bits. Los tres tienen que coincidir con el PHP que se instale en la PC nueva.
  • Se descargan gratis de Microsoft: buscar "Microsoft Drivers for PHP for SQL Server download" (repo oficial en GitHub: microsoft/msphpsql). Bajar el paquete, y de ahí copiar SOLO los dos .dll que dicen _82_ts_x64 (o el número que corresponda a la versión de PHP que se instale) a C:\xampp\php\ext\.
  • Después agregar al php.ini:
    extension=php_sqlsrv_82_ts_x64.dll
    extension=php_pdo_sqlsrv_82_ts_x64.dll

🔴 Microsoft Visual C++ 2015-2022 Redistributable (x64) Obligatorio

Lo necesitan tanto php8apache2_4.dll (compilado con VC16 / Visual Studio 2019) como el ODBC Driver 18. En Windows 11 suele venir preinstalado, pero en un Windows más viejo o "limpio" puede faltar — si Apache no arranca sin ningún error visible en el log, esto es lo primero a revisar.

5 Servidor web

Apache 2.4.56 (XAMPP para Windows) Recomendado instalar igual

La forma más simple de tener PHP 8.2.4 TS x64 + Apache 2.4.56 con la combinación correcta ya armada es instalar el mismo instalador de XAMPP que se usó acá (XAMPP con PHP 8.2.x para Windows), en vez de armar Apache y PHP por separado a mano.

El proyecto vive como junction (enlace de directorio) desde C:\xampp\htdocs\portal_apm hacia el repo real — no hace falta copiar archivos, se puede crear el junction de nuevo en la PC destino apuntando a donde quede el repo clonado.

7 Instalación desde cero (clon nuevo, sin copiar el equipo actual)

Para cuando NO se está migrando este equipo con sus datos, sino levantando una copia nueva — por ejemplo para otro desarrollador, o un ambiente de pruebas separado.

7.1 · Clonar el repositorio

Ubicarlo dentro de htdocs de XAMPP (o crear un junction hacia donde quede el repo, que es como está armado este equipo — ver sección 5):

cd C:\xampp\htdocs
git clone <url-del-repo> portal_apm

7.2 · Base de datos — dos caminos, elegir uno

Camino A — restaurar los backups reales (recomendado, trae datos):

  • Este proyecto incluye INDICACIONES/generar_backups_sql2014.ps1, que genera un .sql autocontenido (CREATE + INSERT, formato compatible desde SQL Server 2014) por cada una de las 5 bases — pensado justamente para llevarlas a otro motor sin depender de un .bak binario atado a la versión exacta del SQL Server de origen.
  • INDICACIONES/backup_completo_5_bases.sql es el script que genera un .bak nativo de las 5 bases (más simple si el SQL Server destino es igual o más nuevo que el de origen — los .bak de SQL Server solo restauran "hacia adelante", nunca a una versión más vieja).
  • Correr el que corresponda, copiar el resultado a la PC nueva, restaurar con SSMS (RESTORE DATABASE para .bak, o simplemente ejecutar el .sql generado).

Camino B — esquema vacío + migraciones (sin datos reales, solo estructura):

  • En Z.BASES DE DATOS/ hay un script por base (PORTAL_APM_COMPLETO.sql, Talento_Humano.sql, inventario.sql, PortuariaDemo.sql, PortuariaExterna.sql) — DROP + CREATE, compatibles desde SQL Server 2014. Ejecutar con SSMS o php db\run_sql.php "ruta\al\script.sql" .\INSTANCIA.
  • Talento_Humano.sql trae datos reales completos (dump de referencia); los otros 3 (aparte de PORTAL_APM_COMPLETO.sql) son solo estructura, sin datos.
  • Obligatorio después: correr las migraciones de TH y Bienes posteriores a esos scripts base, o el login propio/MFA/bloqueo de TH y algunas pantallas de Bienes fallan con "Invalid column name". Ver apps/talento_humano/database/th_schema_migrations (tabla de control) o simplemente correr, en orden, todo lo que hay en apps/talento_humano/database/*.sql que no esté ya reflejado ahí — el propio run_sql.php deja registro de lo aplicado. Mismo criterio para apps/control_bienes/database/migrations/*.sql.

7.3 · Configurar la conexión

copy config\connections.example.php config\connections.php y editar server_default con el nombre real de la instancia SQL Server de la PC nueva (Windows Auth por defecto — usuario/clave vacíos).

apps/control_bienes necesita además copy apps\control_bienes\.env.example apps\control_bienes\.env — con DB_HOST vacío hereda el servidor de connections.php. apps/talento_humano no necesita .env propio.

7.4 · mod_rewrite (si no se usa XAMPP igual que este equipo)

XAMPP para Windows trae rewrite_module activo por defecto — no suele haber que tocar nada. Si se usa WampServer en cambio: Wampmanager (ícono en bandeja) → Apache → Apache modules → marcar rewrite_module (reinicia Apache solo). Sin esto, la home carga pero el resto de las rutas (/login, /dashboard, etc.) da 404.

7.5 · Extensión dbase (opcional, solo un desplegable puntual)

El desplegable de funcionarios en Bitácoras → Visitas → Registrar lee un archivo legacy Visual FoxPro (apps/bitacoras/dbf/rolmaes.DBF) con la extensión PHP dbase. Sin ella, el resto del portal funciona igual — solo ese desplegable queda vacío. Se baja de PECL (pecl.php.net/package/dbase), build x64/TS que coincida con la versión de PHP instalada. Detalle con capturas: apps/bitacoras/dbf/INSTALAR_EXTENSION_DBASE.md.

9 Checklist — migrar este equipo tal cual

  • 1. Instalar Microsoft Visual C++ 2015-2022 Redistributable (x64).
  • 2. Instalar Microsoft ODBC Driver 18 for SQL Server (x64).
  • 3. Instalar SQL Server 2022 (Express alcanza), con una instancia — puede llamarse distinto a VICTUS, pero después hay que actualizar config/connections.php → server_default con el nombre real.
  • 4. Restaurar las 5 bases (PORTAL_APM, Talento_Humano, PortuariaDemo, PortuariaExterna, inventario) desde el backup real — ver sección 7.2, Camino A.
  • 5. Instalar XAMPP para Windows con PHP 8.2.x (verificar que trae el build TS, no NTS).
  • 6. Descargar Microsoft Drivers for PHP for SQL Server, copiar php_sqlsrv_82_ts_x64.dll y php_pdo_sqlsrv_82_ts_x64.dll a php/ext/.
  • 7. Agregar las 2 líneas extension=... de sqlsrv al php.ini, más las extensiones de la sección 3 (la mayoría ya vienen activas por default en XAMPP: curl, mbstring, openssl, intl, etc. — revisar que ninguna esté comentada con ;).
  • 8. Instalar gd también (recomendado, no obligatorio).
  • 9. Copiar los valores de php.ini de la sección 6 (sobre todo date.timezone, upload_max_filesize, post_max_size).
  • 10. Clonar el repo, crear el junction/symlink de htdocs\portal_apm hacia el repo (o copiar directo si no se quiere junction).
  • 11. Editar config/connections.php con el nombre real de la instancia SQL Server de la PC nueva y credenciales si no es Windows Auth.
  • 12. Reiniciar Apache, probar login en el portal y en cada módulo (Portal, TH, Bienes, Bitácoras), confirmar que las 4 conexiones a BD levantan.
